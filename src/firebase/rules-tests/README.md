# בדיקות כללי אבטחה (Firestore + Storage)

הבדיקות רצות על האמולטור המקומי של Firebase, לא על הפרויקט האמיתי, ולא נוגעות בנתונים.

דרישות: Node 18 ומעלה, Java 11 ומעלה (האמולטור צריך Java).

```
cd src/firebase/rules-tests
npm install
npm test
```

תוצאה צפויה: `92 passed, 0 failed` ואחריה `7 passed, 0 failed`.

`test.mjs` בודק את הכללים החיים (`../firestore.rules`), כולל ההקשחה מ-5 בנובמבר 2026: צורת רשומת ספר ושחזור, יומן פעולות שלא ניתן לזייף, `email_verified`, וגבאי כספים שלא משנה מייל קיים.
כל שינוי עתידי בכללים: להריץ שוב לפני פרסום. בדיקה שנכשלת = לא לפרסם.
