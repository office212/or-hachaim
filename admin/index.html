MOCK ONLY No login is wired yet (placeholder). No data is saved to a live backend. In the Firebase phase, Google login gates this page and Firestore stores every change.

Permissions model (documented, not enforced here yet): super admin hanochhason@gmail.com chooses per gabbai: finance only, times/screen only, or both. A gabbai with screen permission edits the items below; a gabbai with finance permission only does not see this page. Every change here is recorded in the activity log in the Firebase phase (who, what, when). The TV screen itself never uses the super admin account: it uses a dedicated synagogue viewer account, screen-read-only, with no finance and no editing access.

Preview before publishing, and change history / תצוגה מקדימה והיסטוריה

Foundation, priority high: before publishing, the gabbai sees the exact TV view at 1920x1080 landscape, including the Shabbat view, by opening the screen page and using its Shabbat preview toggle. Every announcement, sponsorship, and dedication has a start and end date and shows only inside its window. Change history with restore of a previous announcement or message is a Firebase-phase requirement, recorded in the activity log; this mock does not yet store history.

Shabbat rules per page / כללי שבת לכל עמוד

Foundation: Shabbat safety is system-enforced, not gabbai memory. Weekday-only items, payment text, and donation QR are hidden automatically on Shabbat and Yom Tov, even if a gabbai forgot to flag them. See src/engines/shabbat-safe.js. Each page also marks its own weekday-only items. On the screen, weekday-only items are hidden from Shabbat entry to Shabbat exit. Use the Shabbat preview toggle on the screen to test this.
