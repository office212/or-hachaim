שחזור נתונים | Restore import

Restore imports MISSING documents only, from a backup JSON file exported by the backup page. It never overwrites an existing document, never deletes anything, and never changes an existing ledger entry. Step 1 is always a dry run, with no writes. Step 2 imports only the documents the dry run listed as missing.
